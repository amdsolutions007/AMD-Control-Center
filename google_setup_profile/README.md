# Google Setup Profile (AMD Solutions 007)

This folder contains a structured, copy/paste-ready setup pack for:
- Google Account Profile (personal profile fields)
- Google Business Profile (GBP) + Google Maps listing
- Google APIs to enable (for professional setup + optional automation)

## What this is
- A **single source of truth** for your brand details so you can set up Google professionally and consistently.

## What this is not
- This does **not** auto-configure your Google account (Google requires interactive setup + verification).
- This does **not** store or expose any API secrets.

- [api_enablement_checklist.md](api_enablement_checklist.md) — Google APIs to enable (by goal)
