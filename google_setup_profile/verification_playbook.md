# Verification + Trust Playbook (GBP)

## Verification
Google will offer one (or more) of these:
- Phone
- Email
- Video verification
- Postcard

Best practice:
- Ensure the **business name + address + phone** match across:
  - Your website
  - GBP
  - Social profiles
  - Any directories you control

## Trust-building (do this immediately after verification)
- Add business hours
- Add services
- Add 10+ photos
- Add a strong description
- Publish your first post/update (if available)
- Turn on messaging (if available)

## Ongoing (weekly)
- Post 1 update/week
- Reply to all reviews
- Add 2 new photos/month
- Keep hours updated for holidays
