## CORE PRINCIPLES

### 1. ZERO TOLERANCE FOR ToS VIOLATIONS
**WE DO NOT build illegal bots or scrapers that violate Platform Terms of Service.**

- Every tool must use Official APIs or manual methods only
- If an API requires payment, we pay or we don't use it
- No gray-hat scraping, no proxy rotation, no ban evasion
- When in doubt, we read the ToS and comply strictly

### 2. ANTI-SPAM DOCTRINE
**WE DO NOT spam. All outreach must be targeted and professional.**

- Every message must be personalized and relevant
- No bulk messaging without explicit opt-in
- Quality over quantity in every campaign
- One unsolicited message per prospect maximum (unless they engage)

### 3. LEGITIMATE API USAGE ONLY
**All APIs used must be Official and Paid for (or Free Tier legitimate).**

- Free Tier: Respect rate limits and usage caps
- Paid Tier: Maintain active billing, pay invoices on time
- No API key sharing or reselling
- No bypassing authentication mechanisms

### 4. RISK ASSESSMENT PROTOCOL
**If a method risks a ban, we discard it immediately.**

- Before implementing any automation:
  - Check Platform ToS (Section: Automated Access)
  - Verify API official documentation
  - Test on personal accounts first
  - Monitor for warning emails/notifications
- At first sign of platform warning: STOP IMMEDIATELY

### 5. IDENTITY PROTECTION PARAMOUNT
**Protect the User's Identity (Olawale Shoyemi) at all costs.**

- Reputation > Revenue (Always)
- No association with spam or black-hat tactics
- Professional communication in all channels
- Build trust, not shortcuts

---

## DECISION FRAMEWORK

When evaluating any new revenue strategy, ask:

```
✅ Is it 100% Legal? (Laws & ToS)
✅ Would I do this with my real name attached? (Reputation)
✅ Can I explain this method to a client without shame? (Ethics)
✅ Does it provide genuine value? (Win-Win)
```

**If ANY answer is NO → REJECT THE METHOD.**
