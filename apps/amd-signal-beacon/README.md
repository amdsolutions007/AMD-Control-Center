# 🚀 AMD Signal Beacon Pro

**RSS Content Engine for African Tech Ecosystem Domination on Leke Leke**

## Overview

A Next.js-powered RSS generator that creates time-gated, branded content feeds for the Leke Leke social platform. Features dynamic hooks, state-specific CTAs, and intelligent content scheduling.

## Architecture

- **Triple Engine System**: Custom content + News aggregation + Community amplification
- **Time-Gated Publishing**: Posts only appear when `publishTime` has passed
- **Dynamic Branding**: Context-aware footers based on content tags
- **Viral Mechanics**: Random hook prefixes for pattern interrupt

## RSS Feed URL

Once deployed: `https://your-domain.vercel.app/api/feed`

## Local Development

```bash
npm install
npm run dev
```

Access feed at: `http://localhost:3005/api/feed`

## Deployment

```bash
vercel --prod
```

## Content Management

Edit `data/posts.json` to queue new content. The RSS feed automatically filters based on current timestamp.
