## 📋 SETUP INSTRUCTIONS

### For Each Feed:
1. Go to Leke Leke → Settings → Auto-Import Feeds
2. Click "+ Add Feed"
3. Paste the RSS URL
4. Set the recommended sync frequency
5. Toggle to "Active"
6. Save

### Recommended Order:
**Day 1**: Add your Signal Beacon + TechCabal + Disrupt Africa

## 🔍 FEED VALIDATION

Before adding any feed, test it:

### Method 1: Browser
Paste the URL in your browser. You should see XML content.

### Method 2: RSS Validator
Visit: https://validator.w3.org/feed/
Paste the feed URL and validate.

### Method 3: Terminal
```bash
curl -I https://techcabal.com/feed/
```
Should return `Content-Type: application/rss+xml` or `text/xml`

## ⚠️ IMPORTANT NOTES

### Feed Reliability
Some feeds may be unstable. If a feed stops working:
1. Check if the source website is online
2. Verify RSS URL hasn't changed
3. Remove and re-add the feed
4. Contact the publication if persists

### Copyright Compliance
- RSS feeds are meant to be syndicated
- You're not modifying content, just aggregating
- Each post links back to original source
- This is standard RSS usage (like Feedly, Flipboard)

### Platform Limits
- Leke Leke may have limits on number of feeds
- Start with 3-5, test performance
- Add more gradually
- Monitor your profile for spam-like appearance
