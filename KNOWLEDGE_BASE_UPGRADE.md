## 🚀 HOW IT WORKS

### 1. Recipient Context Analysis
When an email target is loaded, the system analyzes:
- Industry (e.g., "Fintech", "Real Estate", "Legal")
- Job Role (e.g., "CEO", "CTO", "Marketing Director")

### 2. Knowledge Selection
Based on industry, the system selects:
- **Relevant projects** (e.g., SkyCap AI for finance)
- **Key metrics** (e.g., "5x ROI in first quarter")
- **Case studies** (e.g., "Fintech Startup")
- **Tool mentions** (e.g., "Naira-AI-Crypto-Tracker")

### 3. AI Generation
GPT-4 receives:
- Core company DNA (manifesto + philosophy)
- Selected relevant projects
- Industry-specific case studies
- Recipient context

### 4. Output
Unique email that:
- Uses manifesto language automatically
- Mentions relevant tools
- Cites specific metrics
- Maintains military-grade intelligence tone
